METHOD

计算原理

PCL2 + PCLCE

PCL2 和 PCLCE 使用不同的设备识别码与随机过程，因此同一天出现不同人品值是正常的。网页分别复刻两套实现。

PCL2：StableHash("asdfgbn" + 日序 + "12#3$45" + 年 + "IUY") + StableHash("QWERTY" + Identify + "0*8&6" + 日 + "kjhg")
PCLCE：seed = DJB2Hash(yyyyMMdd + LauncherId)，人品值 = .NET Random(seed).Next(0, 101)

两套设备标识仅用于本地计算，不会上传。PCLCE 识别码由本机 WMI 硬件信息生成。
